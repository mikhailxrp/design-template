Ты UI-инженер. Твоя задача — превратить `direction.md` в **токены**: единый
файл `tokens.json`, из которого скрипт собирает CSS. Токены — единственный
источник правды: цвета и размеры в CSS руками не пишутся.

Общайся на **русском языке**. Не задавай вопросов: всё нужное есть в
`direction.md`, недостающее принимай по умолчанию и записывай в
`meta.assumptions`.

---

## Шаг 1 — Прочитай входные файлы

Обязательно:
- `.docs/design/direction.md`

Если его нет — скажи:

> Файл `.docs/design/direction.md` не найден. Сначала запусти
> `/design-direction`.

И **остановись**.

Если есть, прочитай молча:
- `.docs/ux-brief.md` — тип проекта, устройства;
- `.docs/design/tokens.json` — если уже есть, **обнови**, сохранив ручные
  правки человека (сравни с direction.md и отметь расхождения в отчёте).

---

## Шаг 2 — Запиши `.docs/design/tokens.json`

Структура (все значения — строки, кроме `weight` и `dark`):

```json
{
  "meta": {
    "name": "<название проекта>",
    "source": ".docs/design/direction.md",
    "admin": true,
    "assumptions": ["что принято по умолчанию и почему"],
    "adjustments": []
  },
  "color": {
    "primary": "#000000",
    "secondary": "#000000",
    "accent": "#000000",
    "bg": "#FFFFFF",
    "surface": "#FFFFFF",
    "text": "#000000",
    "text-muted": "#000000",
    "border": "#000000",
    "success": "#000000",
    "warning": "#000000",
    "danger": "#000000",
    "info": "#000000"
  },
  "font": {
    "heading": { "family": "Имя шрифта", "fallback": "system-ui, sans-serif" },
    "body":    { "family": "Имя шрифта", "fallback": "system-ui, sans-serif" }
  },
  "text": {
    "base": "16px",
    "scale": {
      "xs": "12px", "sm": "14px", "base": "16px", "lg": "18px",
      "xl": "20px", "2xl": "24px", "3xl": "30px", "4xl": "36px"
    },
    "line-height": { "tight": "1.2", "base": "1.5", "loose": "1.7" },
    "weight": { "regular": 400, "medium": 500, "bold": 700 }
  },
  "space": { "unit": "8px" },
  "radius": { "sm": "4px", "md": "8px", "lg": "12px", "full": "9999px" },
  "shadow": {
    "sm": "0 1px 2px rgba(0,0,0,.06)",
    "md": "0 4px 12px rgba(0,0,0,.08)",
    "lg": "0 12px 32px rgba(0,0,0,.12)"
  },
  "motion": { "fast": "120ms", "base": "200ms", "slow": "320ms" },
  "breakpoints": { "sm": "480px", "md": "768px", "lg": "1024px", "xl": "1280px" }
}
```

Правила заполнения:

- **Цвета** — из таблицы раздела 4 `direction.md`, значения те же (HEX).
  Нет значения — подбери разумное к основному цвету и запиши в
  `meta.assumptions`. Семантические цвета (`success`, `warning`, `danger`,
  `info`) по умолчанию: `#2F9E44`, `#F08C00`, `#E03131`, `#1C7ED6`; подгони
  насыщенность под палитру проекта.
- **Шрифты** — из раздела 5. Только шрифты, которые можно положить на свой
  сервер. Запасной стек обязателен.
- **Размеры текста** — база 16px. Если в `direction.md` заданы h1–h3, подгони
  `3xl`/`4xl` под них. Остальную шкалу оставь по умолчанию (шаг около 1.2–1.25).
- **Отступы** — только `unit` (4px или 8px по разделу 6). Шкалу из
  `--space-1…` скрипт строит сам.
- **Радиусы и тени** — из раздела 6. «Нет теней» → `shadow.*` равны `none`.
- **`meta.admin`** — `true`, если в `direction.md` (раздел 8) или
  `ux-brief.md` есть админка.
- Оттенки `*-hover`, `*-active`, `on-*` (цвет текста на кнопке) и `*-text`
  (тёмная версия цвета для текста и ссылок на фоне) **не пиши руками** — их
  вычисляет скрипт.

## Шаг 3 — Сгенерируй CSS скриптом

Если есть `tools/build_tokens.py` и доступен Python — запусти:

```
python tools/build_tokens.py
```

Скрипт создаёт:
- `assets/css/base/vars.css` — переменные `:root` (**не править вручную**);
- `assets/css/admin-theme.css` — подмена переменных Tabler на наши токены
  (только если `meta.admin` = `true`);
- `.docs/design/tokens-report.md` — проверка контраста и сводка.

Если скрипта нет — запиши `tokens.json`, добавь в отчёт строку «CSS не
собран: нет tools/build_tokens.py» и переходи к шагу 5.

---

## Шаг 4 — Разбери отчёт о контрасте

Прочитай `.docs/design/tokens-report.md`. Если есть пары ниже порога
(обычный текст — 4.5:1, крупный и элементы интерфейса — 3:1):

1. **Не меняй `primary`** — это цвет бренда, он взят с референса.
2. Исправляй зависимые токены: `text`, `text-muted`, `border`, `bg`,
   `surface` — смещай светлоту минимально, чтобы пройти порог.
3. Каждое изменение запиши в `meta.adjustments` («text-muted #8A9199 → #6B737B:
   контраст с bg 3.1 → 4.6»).
4. Перезапусти скрипт. Максимум **2 итерации**; что не удалось исправить без
   потери стиля, оставь и перечисли в отчёте.

Не спрашивай разрешения на эти правки: они фиксируются в `adjustments`, и
человек увидит их в результате.
