# design-template — правила для Claude Code

Единый источник правил проекта — файл `AGENTS.md` в корне репозитория.

@AGENTS.md

Если содержимое `AGENTS.md` не подгрузилось автоматически, обязательно прочитай
`AGENTS.md` целиком перед началом работы.

Slash-команды Claude Code находятся в `.claude/commands/*.md` и ссылаются на
канонические инструкции шагов в `.agents/skills/<имя>/SKILL.md`.
